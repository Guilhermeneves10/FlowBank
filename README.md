# FlowBank
Sistema bancário desenvolvido em Java como projeto acadêmico. A aplicação permite o gerenciamento de contas, realizando operações como cadastro de usuários, login, depósito, saque e consulta de saldo utilizando MySQL como banco de dados.

Tecnologias utilizadas

- Java
- NetBeans IDE
- Apache Ant
- MySQL (se utilizar)
- Git e GitHub

## Funcionalidades

- Cadastro de usuários
- Login
- Operações bancárias
- Gerenciamento de contas

## Como executar

1. Baixe o projeto
2. Abra no NetBeans
